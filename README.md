# Unified Flasher

**One Windows app for Android + iOS firmware flashing.**

Unified Flasher brings Fastboot, SP Flash Tool, MTKClient, Odin, SP Flash Lite and iOS restore into one clean desktop workflow — with device detection, live logs, firmware validation and per-PC licensing.

## Requirements

- Windows 10 or Windows 11 (64-bit)
- 8 GB RAM recommended
- USB cable and the correct drivers for your phone
- Internet connection for the first activation and periodic license refresh

## Install

1. Download **UnifiedFlasher-Setup-1.0.0-x64.exe**.
2. Run it. Because the build is not code-signed yet, Windows SmartScreen may show a warning — click **More info → Run anyway**.
3. Open **Unified Flasher**.
4. Paste your license key and click **Activate**. The key locks to that PC.
5. Connect your device and pick a tool from the sidebar.

## Included Tools

- **Fastboot** — bootloader and partition flashing
- **SP Flash Tool** — MediaTek scatter firmware workflow
- **MTKClient** — MediaTek bootrom / preloader operations
- **Odin** — Samsung firmware flashing
- **SP Flash Lite** — lightweight MediaTek flashing
- **iOS Restore** — iPhone restore workflow

SP Flash Tool and Odin are **not bundled**. The app links to the official vendor download and shows a setup guide.
